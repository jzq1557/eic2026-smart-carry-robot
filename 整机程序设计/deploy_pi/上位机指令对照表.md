# 上位机指令对照表（树莓派端）

> 更新时间: 2026-09-05
> 适用范围: `~/vision_robot/` 下的视觉瞄准/标定脚本（树莓派），配合下位机固件 `26090501TEST`
> 硬件: 摄像头(1280x720) + USB-TTL(`/dev/ttyUSB0`)→STM32 PA9/PA10

## 〇、通用参数（几乎所有脚本都支持）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--port` | `/dev/ttyUSB0` | STM32 串口设备（换口时改） |
| `--baud` | `115200` | 波特率（一般不用改） |
| `--cam` | 自动 | 摄像头索引。默认自动尝试 0/1/2/3；**video0 漂移时指定**，如 `--cam 1` |
| `--demo` | 关 | 不连串口、不动电机，只跑视觉（纯看检测/算偏差用） |
| `--show` | 关 | 弹窗显示画面（SSH 无显示器时不要用） |
| `--stream N` | 关 | 起 MJPEG 推流，浏览器看 `http://<树莓派IP>:N/` |

## 一、aim_and_place.py —— 瞄准 / 归位 / 夹料 / 放料

### 1. 模式参数（核心指令）

| 指令 | 作用 | 机械流程 | 输出/产物 |
|---|---|---|---|
| `--mission` | **全流程**: 瞄准→归位→夹料→放料 | 瞄准(记offset) → base/arm反向归观察位 → 发 `0x16 <slot>` 去车载物架对应位夹料 → 回放offset回靶心 → 发0x13放料 | `aim_offset.txt` |
| `--mission-all` | **三料全流程**(2026-09-12 新增) | 瞄准一次 → 依次对物架 **1/2/3 号位**各做一遍: 归位 → 夹料 → 回放 → 放料 | `aim_offset.txt` |
| (无模式参数) | **只瞄准** | 夹爪张开0° → X1校base-x → Y校伸缩-y → X2复校base-x → 记录偏移 | `aim_offset.txt` |
| `--home` | **归位** | 读 offset，base/arm 反向走回观察位（瞄准后、夹料前用） | — |
| `--grab [--slot N]` | **去车载物架夹料** | 发 `0x16 <slot>` → 下位机 `TTLctrl_Act_GrabFromVehicle(slot)`(1/2/3 号位各自动作组) | — |
| `--replay` | **回放+放料** | 读 offset → base/arm 正向走回靶心 → 发 0x13 放料动作组 | — |

### 2. 典型组合（现场实际输入）

```bash
# ① 只瞄准 + 推流(常用调试)
python3 aim_and_place.py --port /dev/ttyUSB0 --stream 8090

# ② 分步流程(推荐, 每步人工确认):
python3 aim_and_place.py --port /dev/ttyUSB0 --home      # 归位
python3 aim_and_place.py --port /dev/ttyUSB0 --grab      # 夹料(默认1号位)
python3 aim_and_place.py --port /dev/ttyUSB0 --grab --slot 2   # 取2号位
python3 aim_and_place.py --port /dev/ttyUSB0 --grab --slot 3   # 取3号位
python3 aim_and_place.py --port /dev/ttyUSB0 --replay    # 回放+放料

# ③ 一条龙全流程(自动, 中间不停):
python3 aim_and_place.py --port /dev/ttyUSB0 --mission            # 单料(slot 默认1)
python3 aim_and_place.py --port /dev/ttyUSB0 --mission-all        # ★三料: 依次取1/2/3号位各放一次

# ④ 不连车纯看画面(demo):
python3 aim_and_place.py --demo --stream 8090
# 摄像头打不开时指定索引:
python3 aim_and_place.py --port /dev/ttyUSB0 --cam 1 --stream 8090
```

### 3. 模式参数可叠加

`--grab` / `--replay` / `--home` 可同时出现（按 home→grab→replay 顺序执行），`--mission` 与它们互斥（mission 内部已含全部）。

## 二、calibrate_aim.py —— 半自动标定 K 系数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--pulses` | `200` | 每轮测试脉冲数（转多少脉冲量圆心移动） |
| `--vel` | `60` | 测试速度 RPM |
| `--cam` | 自动 | 摄像头索引 |

```bash
python3 calibrate_aim.py --port /dev/ttyUSB0
python3 calibrate_aim.py --port /dev/ttyUSB0 --pulses 100 --vel 40   # 步幅小一点
```

**运行流程**：先 base 轴 dir0/dir1 各测一轮 → 再伸缩台 dir0/dir1 → 打印建议值：
```
K_PX2STEP_BASE = 0.2593     ← 填进 aim_and_place.py 顶部
K_PX2STEP_ARM  = 0.0413
```
换分辨率/机械改动后必须重标。

## 四、指令 → 下位机协议命令对照（内部行为）

| 上位机操作 | 发到下位机的帧 | 下位机动作 |
|---|---|---|
| 瞄准夹爪张开 | `0xFF 0x15 0x00 ... 0xFE` | `Grip_Angle(0)` 爪子张开0°不遮挡 |
| 瞄准 X 校 base | `0xFF 0x12 dir vel_h vel_l clk32 ...` | `TTLctrl_Motor4()` id4 base轴微转 |
| 瞄准 Y 校伸缩 | `0xFF 0x10 dir vel ...` | `TTLctrl_Motor1()` id1 伸缩台微调 |
| `--home` 归位 | 0x12 / 0x10 反向命令 | base/arm 回观察位 |
| `--grab [--slot N]` | `0xFF 0x16 <slot> ...0xFE` | `TTLctrl_Act_GrabFromVehicle(slot)` 去物架夹料; slot=1/2/3 → 1 号位 base 正转1700 / 2 号位 base 不动 / 3 号位 base 反转1700(其余动作同序,末尾均回观察位) |
| `--replay` 回放 | 0x12 / 0x10 正向命令 | base/arm 回靶心 |
| `--replay` 放料 | `0xFF 0x13 ...0xFE` | `TTLctrl_Act_Place()` 下放-开爪-抬升 |
| 回执 | `0xFF 0x01 0xFE` | 非阻塞命令(0x10~0x12 电机等)即时回执; 阻塞动作组 **0x13/0x16 整组完成后才回执**, 上位机最多等 25s(aim_and_place 已按此实现, 勿把下一帧塞进下位机忙时) |
