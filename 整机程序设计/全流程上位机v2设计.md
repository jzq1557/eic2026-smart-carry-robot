## 1. 目标与非目标

目标: 一键启动后, 机器人按现场任务码自主完成"读码→两批取料→放粗加工/暂存(含码垛)→回启停→
统计显示", 全程不卡死、可安全中止、日志可复盘。
非目标(本版不实现): 车道视觉循迹/避障感知算法调参(需场地)、现场标定值自动求解、多机并发控制以外
的调度优化。**每个"未实现"处给出口(接口/占位函数), 不内联写死。**

## 2. 分层架构(数据流自上而下)

```
┌────────────────────────────────────────────────────────┐
│ 入口 main(一键启动/安全中止/日志目录)                    │
│   plan  = task_code_v2.parse_task_code(qr_text)         │
│   stats = task_stats.RunStats(plan["raw"])              │
│   runner= FlowRunner(exec, ctx, stats, cfg)             │
│   runner.run(plan)                                      │
└──────────────┬─────────────────────────────────────────┘
┌──────────────▼─────────────────────────────────────────┐
│ 编排层 FlowRunner: 分阶段状态机 + 超时/重试/日志        │
│   阶段: 读码 → 批1取料 → 批1粗加工放 → 批1暂存放(搬)     │
│         → 批2取料 → 批2粗加工放 → 批2暂存码垛 → 回启停   │
│   规则看门狗: 静止>15s(等转盘+8s)判负 → 中止并留日志     │
└──────────────┬─────────────────────────────────────────┘
┌──────────────▼─────────────────────────────────────────┐
│ 执行适配层 Executor(按真机实现/注入)                    │
│   send_frame(cmd, wait_s)  0xFF 帧 + ACK + 重试(≤3次)   │
│   aim/视觉握手: RingDetector / QRDetector / ColorDetector│
└──────────────┬─────────────────────────────────────────┘
┌──────────────▼─────────────────────────────────────────┐
│ 下位机: USART1 PA9/PA10 115200, 0xFF+8B+0xFE, 大端     │
│   旧车协议 0x01~0x0D / 新车 TTL 0x10~0x16 (见 car_config)│
└────────────────────────────────────────────────────────┘
```

## 3. 组件职责与已有地基映射

| 层/组件 | 职责 | 现状/落点 |
|---|---|---|
| 任务码解析 | 15字符4组 → 两批 {颜色顺序, 环位} | ✅ task_code_v2.py(替换旧 get_taskinfo) |
| 统计/显示账本 | 抓取正确/放置正确/环分/完成态; display_lines() | ✅ task_stats.py |
| 串口协议基元 | 帧构造/ACK/长等待/重试 | ✅ deploy_pi aim_and_place.Lower(可抽成独立模块复用) |
| 编排状态机 | 阶段流、看门狗、超时、中止、日志 | ⏳ 本蓝图 v2 待写(纯逻辑, 注入 Executor 即可本地单测) |
| 二维码读码 | 前视相机 QR → qr_text | ✅ qr_stream_demo 逻辑(图片模式可离线条测) |
| 圆环识别 | 放置靶标对心 | ✅ ring_center_detect_v2 + aim_and_place 瞄准闭环 |
| 物料颜色/形状识别 | 转盘上目标色块 | ⚠️ 现场取色后定阈值(probe_palette.py 已备); 旧色表已废 |
| 显示装置驱动 | 显示任务码+统计 | ⏳ 需按装置(OLED/串口屏)写驱动, 数据来自 task_stats |
| 运动原语表 | 命名动作 → 帧序列 | ⚠️ 与车架/坐标系绑定, 车上定稿; 旧车见 legacy 协议, 新车见 TTL 0x10~0x16 |

## 4. 与旧上位机高危项对照(验收准则)

1. 任务码 4 组解析: ✅ 已修(task_code_v2), 非法码显式报错且**不崩溃、可重扫**。
2. 颜色编号官方化: ✅ 红1..浅蓝6 内建; 旧 [0,red,green,blue] 不再出现。
3. 放置位置按任务码(组2/4): 新 plan 直接携带 places; 删除旧"固定颜色→环位"映射。
4. 全链路超时: 编排层统一看门狗 + 每步 timeout + ACK 重试; 任一超时 → 记录并安全中止
   (宁可本轮低分, 不触发"静止15秒判负"后的 0 分…… 仍须现场按规则定中止阈值)。
5. 异常/日志: FlowRunner 顶层 try/except + 结构化日志文件(时间戳/阶段/指令/结果), 供复盘。
6. 第 3 个物料混合动作: 改为"动作原语表"显式展开, 不依赖下位机隐藏状态。
7. 统计/显示: task_stats 提供数据源; 显示驱动单独实现。
8. HSV 通道: 新颜色识别**整表重标**(勿沿用 RGB2HSV 通道互换旧表), 用现场实拍图。

## 5. 落地顺序建议(依赖现场)

1. ✅ 纯逻辑(已完成, 本机可验): FlowRunner 骨架 + 三套回归
   (任务码解析9 / 统计5 / 编排7, 均已挂 .vscode tasks 一键运行)。
2. 真机 Executor 适配器: 0xFF 串口帧(旧车 0x01~0x0D / 新车 0x10~0x16 各一份
   配置) + 视觉握手(读码/色/环); 需车上联调定稿。
3. 现场: 烧固件 → 手动逐原语验证 → 收集各段耗时/坐标 → 填 cfg(标定文件)。
4. 再联调: 视觉握手 + 看门狗阈值实调。
5. 显示装置驱动 + 一键启动收尾。
