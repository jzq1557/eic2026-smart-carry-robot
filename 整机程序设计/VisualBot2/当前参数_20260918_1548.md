## 二、动作组实际脉冲

grab_demo 放物架 9 步（② 按 `RACK_TURN_DEG[n]` 折算）：

```
① lift_up   2800 @40      ② base_right  2933 @40   ③ arm_in  6500 @200
④ lift_down  300 @30      ⑤ grip_open   —          ⑥ lift_up   800 @40
⑦ arm_out   6500 @200     ⑧ base_left   2933 @40   ⑨ lift_down 3300 @30
```

place_demo 从物架取料 9 步（= 上面整组**反向**）：

```
① lift_up   3300 @40      ② base_right  2933 @40   ③ arm_in  6500 @200
④ lift_down  800 @30      ⑤ grip_close  —          ⑥ lift_up   300 @40
⑦ arm_out   6500 @200     ⑧ base_left   2933 @40   ⑨ lift_down 2800 @30
```

place_demo 放到标靶 3 步：

```
① lift_down 3500 @30      ② grip_open   —          ③ lift_up  3500 @40
```

### 高度账验算（H = 瞄准高度，单位：脉冲）

| | 料位 | 全程最高点 | 收工 |
|---|---|---|---|
| grab_demo 放物架 | H+2800−300 = **H+2500** | H+2800−300+800 = **H+3300** | ⑨ 下放 3300 → **H** ✓ |
| place_demo 取料 | H+3300−800 = **H+2500** | **H+3300** | ⑨ 下放 2800 → **H** ✓ |

⇒ 两边**料位一致（H+2500）**、最高点一致（H+3300，与 `RACK_LIFT_UP=2800` 同量级，
在龙门行程内），收工都精确回到瞄准高度。**账平且不顶限位** ✓

## 三、等待时间（2026-09-18 起：匀速段 + 加减速段）

固件对 `0x10/0x11/0x12` 是**非阻塞**的（`TTLctrl.c`「发完即返回,不等待」），
上位机按 `脉冲×60/(RPM×3200) + 2×RPM/TTL_ACC_RPM_PER_S + 0.25` 估时
（`school_config.TTL_ACC_RPM_PER_S = 300`）。

| 动作 | 匀速 | 加减速 | 合计 |
|---|---|---|---|
| `arm_in/out 6500 @200` | 0.61s | 1.33s | **2.19s** |
| `lift_up 3300 @40` | 1.55s | 0.27s | **2.07s** |
| `lift_down 3300 @30` | 2.06s | 0.20s | **2.51s** |
| `base 2933 @40` | 1.37s | 0.27s | **1.89s** |
| `lift_down 3500 @30` | 2.19s | 0.20s | **2.64s** |
| `lift_up 800 @40` | 0.38s | 0.27s | **0.90s** |
| `lift_down 2800 @30` | 1.75s | 0.20s | **2.20s** |

> 速度调得越高，加减速占比越大 —— 老公式（只算匀速）在 200RPM 下少等 1.3 秒，
> 现场现象就是"伸缩台还没到位，龙门架和舵机动作已经开始执行"。
