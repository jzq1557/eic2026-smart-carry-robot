# 现场标定手册（到场地后照这个顺序做）

> 配套：`校赛开发.md`（规则/架构/六次瞄准）、`README.md`（工程总览/坑档案）、`整机程序设计\校赛\`（主程序与工具）
> 原则：**先机械后视觉、先单点后全程、每步都要有可量化的验收标准**；标定结果都存文件，随时可回滚。
> 全程预计 **6~9 小时**（第一天建议只做到第 9 步，第二天再做联调）。

---

## 0. 总览：顺序与依赖（别跳步）

| 步骤 | 内容 | 依赖 | 预计 | 产物 |
|---|---|---|---|---|
| 1 | 硬件/系统上线检查 | — | 30min | 相机编号、固件版本确认 |
| 2 | **机械臂行程 + 夹爪** | 下位机在线 | 60min | `school_main.py` 的脉冲/角度参数 |
| 3 | 相机安装与**对焦** | 相机 | 30min | 清晰画面 |
| 4 | **圆环检测**标定 | 相机能看清靶标 | 60min | `ring_calib.json` |
| 5 | 数字模板热加载 | 步骤 4 | 15min | `digit_custom/1,2,3/*.png` |
| 6 | **颜色**阈值标定 | 相机 + 真实物料 | 40min | `color_profile.json` |
| 7 | **瞄准 K + 夹爪偏移** | 步骤 2/4 | 60min | `school_config.py` 的 K / OFFSET |
| 8 | 扫码标定 | 侧装相机 + 任务码 | 20min | 相机参数 + 超时 |

## 2. 机械臂行程 + 夹爪（60 min，**不用视觉**）

目的：把每个轴"从 A 到 B 需要多少脉冲/多少度"量准。**这一步做错，后面全白干。**

工具：直接用 `car.py` 的动作（一条条试），建议先 `--dry-run` 看命令、再真发：

```bash
cd 校赛
python3 - <<'PY'
from car import Car
c = Car(port="/dev/ttyUSB0")
c.setup(chassis_vel=8, chassis_acc=6, chassis_dec=3,
        grip_close_angle=82, grip_open_angle=50, base90=6400,
        lift_up=4400, lift_down=4400, telescope=3000, ttl_vel=40)
# —— 逐个试，每次改括号里的数字 ——
c.arm_out(3000, 30)      # 伸缩前伸：量"伸出去多少 cm"，够到物料/靶心就停
c.arm_in(3000, 40)
c.lift_down(4400, 30)    # 龙门架下放（id2/id3 反向传动）
c.lift_up(4400, 40)
c.base_left(6400, 40)    # base 左转 90°：用直角尺量，转多了减、少了加
c.base_right(6400, 40)
c.grip_open(); c.grip_close()   # 舵机角度（见下）
c.close()
PY
```

| 标定项 | 判断标准 | 落在哪 |
|---|---|---|
| `TELESCOPE` 前伸 | 伸到"夹爪正好罩住物料"、不撞工件 | `school_main.py` 参数区 |
| `TELESCOPE` 收回 | 收回到不挡视觉、不撞自身 | 同上 |
| `LIFT_UP/LIFT_DOWN` | 下放到"物料贴台面"、抬起后离台 3~5cm | 同上 |
| `BASE_90` | 左转**正好 90°**（直角尺/地面上画线比对） | 同上 |
| 夹爪角度 | 张开能套住物料、闭合后**抽出物料打滑 = 夹太松**；夹不住 = 角度不够 | 舵机角度：`GRIP_OPEN_ANGLE=50 / GRIP_CLOSE_ANGLE=82`（固件 `car_config.h` 的 `SERVO_GRIP_*` 是默认值，上位机 `setup()` 下发可覆盖） |
| 腕关节 | 本流程不用，跳过 | — |

⚠️ **夹爪是舵机（0x14/0x15，角度制）**，不是 TTL 脉冲——别再去调"1700 脉冲"那种东西。
⚠️ 夹爪力度：`Grip_Close()` 若顶死会堵转发热，宁松勿紧（物料掉了比烧舵机强）。

**验收**：连续做 5 次"前伸→夹→收回→张开"，物料每次都在同一位置、不掉。

## 3. 相机安装与对焦（30 min）

```bash
cd /root/VisualBot_current
python3 focus_assist.py --stream 8090        # 浏览器看清晰度分数（拉普拉斯方差）
# 或直接用双摄监控台一边看一边拧
python3 -u monitor_ui.py --work-cam <作业相机> --scan-cam <扫码相机> --perf rdk --port 8092
```
- 作业相机：**对着要瞄的靶心/物料中心**，画面中心 = 夹爪作业中心（后面用 OFFSET 补偿安装偏差）
- 扫码相机：**对着任务码**，距离 = 实际通过时相机到码的距离
- ⚠️ 先**拧镜头对焦**（LRCP G720P 是定焦+螺纹镜头），拧到分数最高/画面最锐
- ⚠️ 这两台相机**不支持手动红蓝增益**（`red_balance/blue_balance max=0`），所以**别锁白平衡**（锁了发青）；
  曝光用 `v4l2-ctl` 才锁得住（`open_camera` 已自动兜底），需要锁时传 `--exposure N`
- [ ] 曝光：`v4l2-ctl -d /dev/videoN -c auto_exposure=3`（先自动）；环境光稳定后再考虑手动锁

**验收**：`monitor_ui` 两路画面都清晰、颜色正常（不青不惨白），fps 稳定。

## 4. 圆环检测标定（60 min）

```bash
python3 ring_stream_ui.py --perf rdk --cam <作业相机> --port 8091
# 浏览器 http://<IP>:8091/   → 把靶标放在实际作业位置，边看边调
```

| 参数 | 什么意思 | 怎么调 |
|---|---|---|
| `rotate_ccw` | 相机是否倒装（画面转 90°） | 画面方向不对就切 |
| `proc_scale` | 检测降采样比（**RDK 上 0.34**） | 越小越快越粗 |
| `thr_block` / `thr_c` | 自适应阈值窗口/偏置（RDK 用 25/5） | 环线断→减小；噪点多→加大 |
| `close_k` | 闭运算核（RDK 用 5） | 环线有缺口→加大 |
| `pre_blur` | 阈值前额外高斯（奇数，1=关） | 噪点多时开 3~5 |
| `min_area_frac` | 最小面积占比 | 误检背景→加大 |
| `center_gate_r` | 环心须落在中心多大范围内 | 现场先 200，瞄准时可 0 |
| `ema` / `jump_px` / `stale_max` | 平滑/突跳重置/丢失保持 | 抖动大→ema 减小、jump 减小 |
| `digit_*` | 数字识别相关（`digit_rot_step`/`digit_votes`/`digit_thr`） | 见步骤 5 |

- 调好后点 **保存档案** → `ring_calib.json`（下次 `--profile` 自动读）
- **验收**：靶标放在三个工位上，每个位置连续看 10 秒：`found=true` 且圆心抖动 < 5px、半径稳定

## 5. 数字模板热加载（15 min）

打印体数字（现场实际用的那种字体/字号）比合成模板更接近实物：
```bash
python3 ring_stream_ui.py --perf rdk --cam <作业相机> --port 8091
# 把数字 1/2/3 分别摆正，点【一键加模板(打印体)】→ 存进 digit_custom/<1|2|3>/*.png
```

- 每个数字加 **5~10 张**（不同角度/不同位置/带一点反光）
- 加完在页面上看 `digit_score`：**> 0.8 才可信**（实测原 0.469 → 加模板后 0.999）
- **验收**：三个数字各自旋转 ±30° 都能稳定识别，投票窗口 20 帧内收敛到正确值

## 6. 颜色阈值标定（40 min，需要真实物料）

```bash
python3 color_blob_stream.py --perf rdk --cam <作业相机> --port 8090
```
- 用**现场真实物料**（红/绿/蓝），逐个：
  1. 颜色下拉选该色 → 点【自动标定(ROI)】框住物料 → 看掩膜是否干净
  2. 手动微调 `H_halfwidth / S_min / S_max / V_min / V_max`
  3. 三色都调好后【保存】→ `color_profile.json`
- ⚠️ **光照要固定**：先把补光灯装好、位置定死，再标颜色（换灯 = 重标）
- ⚠️ 暗色/反光物料：先把 `blur_k`/`pre_blur` 开起来降噪（否则掩膜会被打碎）
- **验收**：三个物料在三个工位上，识别结果与真值一致；把物料转动 90° 仍能识别

## 7. 瞄准 K 与夹爪偏移（60 min）

```bash
python3 calibrate_aim.py --port /dev/ttyUSB0     # 半自动：发固定脉冲 → 看画面位移 → 算 K
```
得到并填回 `校赛\school_config.py`（以及 `deploy_pi\aim_and_place.py` 顶部）：
```python
K_PX2STEP_BASE = 0.2593     # base 轴：像素/脉冲（现场重标）
K_PX2STEP_ARM  = 0.0413     # 伸缩轴：像素/脉冲
CAM_GRIP_OFFSET_X = 0.0     # 夹爪相对光轴的横向偏差（px）
CAM_GRIP_OFFSET_Y = 0.0     # 纵向偏差（px）
```

**夹爪偏移怎么量**：把物料放到**夹爪正下方（夹爪能夹住的位置）**，此时读画面里圆心像素：
```
OFFSET_X = 圆心x − 画面宽/2
OFFSET_Y = 圆心y − 画面高/2
例：1280×720 画面里圆心在 (700, 400) → OFFSET_X=+60, OFFSET_Y=+40
```

**验收**（架空或低速试）：
```bash
cd 校赛 && python3 -u school_main.py --dry-run --code 123+321   # 先看逻辑
python3 - <<'PY'
from car import Car
c = Car(port="/dev/ttyUSB0"); c.use_camera(cam_index=<作业相机>, perf="rdk")
ok, off = c.aim(tag="TEST")     # 收敛一次，看日志里 dx/dy 是否收敛到 ±8px
print("收敛=", ok, "偏移=", off)
c.close()
PY
```
- 收敛 ≤ 8px、连续 2 帧稳定 → 通过
- 收敛后夹爪应正好在物料正上方（差个 1~2cm 就用 OFFSET 修）

- **验收**：连扫 10 次，10 次都得到同一个正确任务码

## 9. 路线里程标定（90 min，用新工具）

```bash
cd 校赛
python3 -u calibrate_route.py --port /dev/ttyUSB0
#   → 选动作（前进/后退/左移/右移/自旋）→ 输每次发多少 → 车动 → 你量实测值
#   → 它算比例并给建议值；最后打印"建议这样改 school_main.py"
```

建议顺序与要点：
1. **前进 60cm** → 量实际 → 2~3 轮收敛；`TO_SCAN / TO_MATERIAL / TO_PROCESS / ENTER_PROCESS / TO_FINISH` 按比例乘
2. **右移 30cm**（出启动区）与 **右移 120cm**（结束时）分别标（长距离误差比例可能不同）→ `RIGHT_OUT / FINISH_RIGHT`
3. **原地自旋 90°** → 用地面上画的基准线量 → `SPIN_DEG`
4. **工位间距**：`MATERIAL_CM[1..3]` 与 `TARGET_CM[1..3]`（实测三个物料/靶位中心之间的距离）

⚠️ 固件里 `STEPS_PER_CM=130 / STEPS_PER_DEGREE=51` 是**硬件换算**：
- 比例在 **0.9~1.1** 之间 → 只改上位机里程（不用重烧！）
- 比例偏离很大（<0.8 或 >1.25）→ 说明换算错了，改 `car_config.h` 并**重烧固件**
⚠️ **长距离要分段走**（一公里偏差靠比例修不回来）：把一段 120cm 拆成两段 60cm，误差更小

**验收**：连续 3 次"前进 60cm"，实际都在 58~62cm；自旋 90° 误差 < 5°。

分阶段推进（每阶段都记时间）：

3. **单次放置**：瞄 → 归位 → 0x16 夹料 → 回放 → 放料
4. **半场**：取 3 个 → 转场 → 放 1 个
5. **全场**：完整跑，**连跑 3 场不掉链子**才算过
